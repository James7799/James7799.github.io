학교 폭력 비디오 행동 인식 · 학교생활안전 CCTV

문제
학교 CCTV에서 배회·침입·폭력을 실시간으로 판정해야 하며, 경보는 사건 시작 후 3~15초 안에 나와야 합니다. 같은 카메라 장면이 학습과 평가에 섞이면 성능이 부풀려집니다.
접근
배회·침입은 사람 감지와 카메라별 구역 규칙으로, 폭력은 세 가지 모델 계열을 같은 중첩 교차검증 프로토콜에서 비교해 결정했습니다. 사건 시점 중심 구간으로만 학습한 시간 모델이 위치 사전확률을 배워 정상 영상 31개 모두에서 경보를 내는 문제를 찾아, 전체 영상 캐시와 무작위 시작 구간 학습으로 고쳤습니다.
결과
사람 쌍 crop MViT-v2-S 앙상블을 배포했고, ffmpeg 무손실 녹화와 raw-PTS 보정으로 패킷 손실을 견디는 실시간 파이프라인에서 Combined F1 96.6을 기록했습니다.

온디바이스 VLM 알람 검증

문제
포즈 기반 TCN은 나란히 걷는 사람이나 앉는 동작을 폭력·낙상으로 오인합니다. 박스의 메모리는 8 GB로, 4채널 추론과 VLM이 함께 들어가야 합니다.
접근
TCN 경보마다 경보 전 6초 구간을 VLM이 다시 보고 확인 또는 거부합니다. 정확도를 우선해 모든 경보에 판정을 내리고, 확인된 경보만 VMS로 보냅니다. 양자화 수준별 판정 정확도를 같은 경보 세트로 비교했습니다.
결과
Q4_K_M이 Q8_0보다 폭력 확인 recall이 높았고, 낙상에서는 '불확실' 판정이 늘어나는 비용을 측정했습니다.

모델 양자화와 이기종 NPU 배포

문제
Ambarella CV2S에서 INT8 모델 출력이 상수로 고정됐고, 컴파일러와 모델이 의심받고 있었습니다. 다른 장비에서는 넘어진 사람을 감지기가 놓쳐 낙상 판정이 시작되지 않았습니다.
접근
최소 재현 코드로 원인을 좁혀, 테스트 하니스가 int16 입력 자리에 float32를 넣고 있었음을 밝혔습니다. LSTM 미지원 NPU에는 LSTM을 Gemm·Sigmoid·Tanh로 직접 풀어 배포했습니다. 감지기는 누운 사람 데이터로 재학습해 DEEPX DX-COM으로 INT8 변환하고, FP32 일치도와 사람 라벨 양쪽으로 검증했습니다.
결과
CV2S 상관계수 약 0 → 0.9948. Segmentation QAT는 mAP50-95 약 1.6% 하락에 그침. 누운 사람 감지는 정밀도 0.98, INT8/FP32 일치도 0.994.

CCTV 기반 강우 강도 추정

문제
침수 위험 경보를 위해 CCTV 한 장으로 시간당 강우량을 추정합니다. 라벨은 같은 장소의 강우계가 자동으로 붙입니다.
접근
첫 모델의 입력에서 빗줄기 채널을 지워 보니 출력이 0.04 미만으로만 변했습니다. 모델이 비가 아니라 학습 현장 벽면의 젖은 모습을 배웠다는 뜻입니다. 정답이 없는 새 카메라에서는 카메라별 AdaBN이 가장 효과가 컸습니다.
결과
맑은 날 오탐 확률이 두 카메라에서 크게 줄었지만, 한 카메라는 거의 그대로여서 다음 실험 방향을 정했습니다.
